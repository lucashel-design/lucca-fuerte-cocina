# Lucca.Fuerte Cocina

A Next.js cooking app that turns meal ideas into structured recipes and guides users through a step-by-step cooking experience with chef-style assistance.

## Overview

Lucca.Fuerte Cocina is a frontend-focused cooking web app built to help users decide what to cook, generate structured recipes, and follow the cooking process step by step.

Instead of showing only a static recipe, the app is designed to guide the user through the full cooking flow, with a more practical and interactive experience inspired by a chef-style assistant.

This project is part of my frontend portfolio and also connects with my previous background in hospitality and cooking.

## Features

- Turn meal ideas into structured recipes
- Recipe output in a clear JSON-based format
- Step-by-step cooking mode
- Timer-based guided flow
- Chef-style assistance experience
- Frontend-focused product thinking
